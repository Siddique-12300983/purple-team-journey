# Scripts

Small tools I've written while building the lab.

| Script | What it does | How to run it |
|---|---|---|
| [roadmap-progress.py](roadmap-progress.py) | Counts the checkboxes in `ROADMAP.md` and redraws the progress bars at the top of `README.md`. A GitHub Action runs it on every push, so ticking a box is enough. | `python3 scripts/roadmap-progress.py` from the repo root |
